# Dokumentace projektu

Soubory v této složce jsou pracovní sumáře projektu (psané v Claude, kopírované sem při každém uzavřeném bloku). Zdroj pravdy pro **data** je `tools/build_opatreni.py` -> `data/opatreni.json`; tyto MD soubory jsou odůvodnění, zdroje a stav.

| soubor | obsah |
|---|---|
| 00-instrukce-projektu.md | účel, území, zásady, fáze, pravidla práce |
| STAV.md | aktuální stav: co je hotové, rozpracované, rozhodnutí, otevřené otázky, předpoklady |
| VRSTVY.md | seznam datových vrstev, WMS adresy, licence (ověřeno 15. 10. 2026) |
| KATALOG.md | seznam opatření a atributy pro filtrování (odsouhlaseno 16. 10. 2026) |
| KATALOG-Z-S.md | kvantifikace: zahrada, dvůr, střecha |
| KATALOG-U-P.md | kvantifikace: veřejný prostor obce, orná půda (vlastníci) |
| KATALOG-L-LES-T-C.md | kvantifikace: louky, les, toky a nivy, cesty a strže |
| DATA-FORMAT.md | struktura opatreni.json |
| ROZHRANI.md | návrh rozhraní aplikace (obrazovky, kroky, co jádro počítá, vrstvy) |
| NAPADY-ROZHRANI.md | zásobník nápadů (posuvníky škál) |

Značky původu informací: ✅ ověřeno online v uvedený den | ✅⏳ ověřeno, zdroj starší 12 měsíců | 📄 doložený zdroj, originál nečten | 🤔 odhad | 💻 z paměti modelu, neověřeno.
